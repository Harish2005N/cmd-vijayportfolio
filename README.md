# Harish N Portfolio

A modern, cinematic, highly interactive personal portfolio website created with HTML, CSS, and JavaScript.

## Overview

This portfolio features a premium movie-intro experience with:
- Cinematic opening animation
- Scroll-based image transformation
- Tamil-English name morphing effect
- Responsive design
- Smooth animations and transitions

## Features

### 1. Opening Cinematic Intro
- Black screen with cinematic text reveal
- "HI, I AM" → "HARISH" animation
- Smooth transition to main portfolio

### 2. Hero Section
- Profile image with cinematic mask effect
- Parallax scrolling effect
- Golden particles and glow effects

### 3. Scroll Transformation
- Image transformation with cinematic effects
- Smooth opacity, scale, and blur transitions
- Golden light particles during transformation

### 4. Name Morphing
- "HARISH" transforms into "ஹரிஷ்" (Tamil)
- Golden color and metallic glow for Tamil text

### 5. Sections
- About Me
- Skills showcase
- Projects gallery
- Achievements & certifications
- Contact information

### 6. Design
- Cinematic premium aesthetic
- Glassmorphism elements
- Smooth animations
- Responsive layout

## Setup

### Prerequisites
- Modern web browser
- VS Code with Live Server extension

### Usage
1. Clone the repository
2. Open `index.html` in VS Code with Live Server
3. Explore the cinematic portfolio

## Development Notes

### Animation Performance
- Uses `requestAnimationFrame` for smooth scrolling
- Optimized with CSS transforms instead of layout properties
- Respects `prefers-reduced-motion` media query
- Lazy loading for better performance

### Image Paths
Update image paths in `index.html`:
```html
<img src="assets/vijay1.jpg" alt="Vijay Portrait">
<img src="assets/vijay2.jpg" alt="Vijay Transformation">
```

### Fonts
The portfolio uses custom fonts loaded via Google Fonts CDN:
- Playfair Display (headings)
- Cormorant Upright (subheadings)
- Inter (body text)
- Noto Sans Tamil (Tamil text)
